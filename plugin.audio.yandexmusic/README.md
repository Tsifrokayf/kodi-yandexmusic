# Яндекс Музыка для Kodi (неофициальный плагин)

Неофициальный аудио-плагин `plugin.audio.yandexmusic` для Kodi 19–22 (Python 3).
Использует неофициальный API Яндекс Музыки через библиотеку `yandex-music` (LGPLv3),
все зависимости вшиты в аддон — внешних зависимостей у Kodi не требуется.

## Возможности

- Вход по коду устройства (OAuth Device Flow) прямо из аддона; альтернатива — ручной OAuth-токен в настройках
- Главная: чарт, новинки, новые плейлисты, персональные плейлисты
- Моя музыка: понравившиеся треки/альбомы/исполнители, мои и понравившиеся плейлисты
- Просмотр плейлистов, альбомов, исполнителей (популярное, дискография, похожие)
- Поиск треков, альбомов, исполнителей и плейлистов (с пагинацией)
- Радио: список станций, тонкая настройка «на этом треке»/«на этом исполнителе»,
  обратная связь ротора (запуск станции, старт трека)
- Управление библиотекой: лайки треков/альбомов/исполнителей, добавление треков в плейлисты
- Воспроизведение: прямые ссылки на поток (MP3/AAC, выбирается в настройках),
  без подписки Яндекс Плюс доступны только короткие превью
- Анимация «сферы» (GIF) как фон секций радио
- Пункт **«Плеер»** в корне — один клик открывает полноэкранный плеер

## Установка

1. Соберите zip (из каталога с аддоном):

   ```sh
   sh ../build_zip.sh
   ```

   Архив появится в **Рабочем столе** с уникальным именем
   `plugin.audio.yandexmusic-<версия>-<дата>.zip` (скрипт чистит `__pycache__`
   и исключает `tests/`). Уникальное имя и ASCII-путь важны: Kodi кэширует
   содержимое zip по пути в памяти сессии, и перезапись архива тем же именем
   «на лету» приводит к сбою установки (`Failed to open file`) до перезапуска Kodi.

2. В Kodi: **Добавки → Установить из zip-файла** → выберите собранный архив.
3. Откройте **Яндекс Музыка → Аккаунт → Войти**, введите отображаемый код на `ya.ru/pair`
   (или укажите OAuth-токен вручную в настройках).

## Обновления

Плагин обновляется через локальный репозиторий **`repository.tsifrokayf`**
(аддон `коди/repository.tsifrokayf`, данные репозитория — `~/Desktop/kodi-repo/`).
Репозиторий устанавливается один раз из zip-файла
`~/Desktop/repository.tsifrokayf-1.0.0.zip` (**Добавки → Установить из zip-файла**).

Раздача репозитория идёт по HTTP — Kodi умеет обновляться только через
http/https, локальные пути в репозитории он не поддерживает:

```sh
nohup python3 -m http.server 8765 --bind 127.0.0.1 \
  --directory "$HOME/Desktop/kodi-repo" > /tmp/kodi-repo-http.log 2>&1 &
```

После перезагрузки компьютера сервер нужно запустить заново; если он не запущен,
«Проверить обновления» покажет ошибку репозитория.

Цикл обновления:

1. `sh ../build_zip.sh` — **каждый запуск повышает patch-версию** в `addon.xml`
   (0.1.1 → 0.1.2 → …), собирает zip и обновляет `kodi-repo/`
   (`addons.xml`, `addons.xml.sha256`, канонический zip
   `<id>/<id>-<версия>.zip` — именно из него Kodi строит ссылку на скачивание).
2. В Kodi: **Добавки → значок шестерёнки → Проверить обновления** →
   появится новая версия → **Обновить**.

## Быстрый доступ из меню Kodi

- **Пункт «Плеер»** в корне аддона открывает полноэкранный плеер
  (визуализацию для музыки, fullscreen для видео). Прямая ссылка:
  `plugin://plugin.audio.yandexmusic/?action=player`.
- **Избранное**: долгое нажатие / контекстное меню на любом пункте →
  *Добавить в избранное*. Избранное появятся на главном экране Kodi
  (Kodi 20+ — раздел «Избранное», также доступны из верхнего меню).
- **Меню «Музыка»** (Kodi 20+): *Настройки → Меню → Музыка →
  Пользовательские пункты меню → Добавить → Добавки → Яндекс Музыка*.
- **Главный экран / виджет** (Kodi 20+): *Настройки → Меню → Главный экран →
  добавить пункт или виджет → Добавки → Яндекс Музыка* (или «Избранное»).
- Готовые ссылки для `favourites.xml`, `script.skinshortcuts` и т. п.:

  | Действие   | URL                                                |
  |------------|----------------------------------------------------|
  | Плеер      | `plugin://plugin.audio.yandexmusic/?action=player` |
  | Главная    | `plugin://plugin.audio.yandexmusic/?action=home`   |
  | Моя музыка | `plugin://plugin.audio.yandexmusic/?action=my`     |
  | Радио      | `plugin://plugin.audio.yandexmusic/?action=radio`  |
  | Поиск      | `plugin://plugin.audio.yandexmusic/?action=search` |

## Структура

```
plugin.audio.yandexmusic/
├── addon.xml                 # метаданные аддона (xbmc.python 3.0.0)
├── default.py                # точка входа
├── icon.png / fanart.jpg     # ассеты
├── resources/
│   ├── settings.xml          # настройки (ручной токен, кодек, TTL кэша)
│   ├── language/             # ru_RU, en_GB (strings.po)
│   ├── media/sphere.gif      # анимация сферы для секции радио
│   └── lib/
│       ├── ymkodi/           # код плагина
│       │   ├── router.py     # роутер: все action-обработчики
│       │   ├── api.py        # сервисный слой поверх yandex_music + кэш + resolve_stream
│       │   ├── auth.py       # device flow, refresh, ручной токен
│       │   ├── player.py     # setResolvedUrl + обратная связь радио
│       │   ├── ui.py         # list item'ы, диалоги, уведомления
│       │   ├── cache.py      # JSON TTL-кэш на диск
│       │   ├── store.py      # хранение сессии (токены)
│       │   └── urls.py       # сборка/разбор plugin:// URL
│       └── vendor/           # вендоренные зависимости
│           ├── yandex_music/ # 3.0.0 (LGPLv3)
│           ├── requests/     # 2.32.3 (Apache-2.0)
│           ├── urllib3/      # 2.2.3 (MIT)
│           ├── idna/         # 3.10 (BSD-3-Clause)
│           ├── chardet/      # 5.2.0 (LGPLv2.1)
│           ├── certifi/      # CA-бандл (MPL-2.0)
│           └── typing_extensions.py
└── tests/                    # юнит-тесты (без Kodi): python3 -m unittest discover
```

## Разработка

```sh
cd tests && python3 -m unittest discover        # чистая логика (38 тестов)
# со стабами Kodi (xbmc/xbmcgui/xbmcplugin/xbmcvfs):
YM_TEST_STUBS=/путь/к/stubs python3 -m unittest discover
```

Проверка аддона: `kodi-addon-checker --branch matrix .`
(допустимо 1 предупреждение — `certifi/cacert.pem`, это рабочий CA-бандл).
Перед проверкой уберите `__pycache__`, появляющиеся от тестов/`py_compile`:

```sh
find . -name __pycache__ -type d -prune -exec rm -rf {} +
```

## Ограничения и дисклеймер

- Это **неофициальный** аддон, использование API Яндекс Музыки не поддерживается Яндексом
  и может в любой момент перестать работать.
- Полноценное прослушивание требует подписки **Яндекс Плюс**; без неё отдаются
  только ~30-секундные превью.
- Лицензия аддона: GPL-2.0-or-later. Вендоренные библиотеки сохраняют свои лицензии
  (`yandex_music` — LGPLv3, `chardet` — LGPLv2.1, `certifi` — MPL-2.0 и т. д.).
